# AirSense ML

## Project Title
Machine Learning-Based Air Quality Analysis and PM2.5 Prediction

## Objective
To analyse historical air-quality data and develop
machine-learning models to predict next-hour PM2.5
concentrations.

## Dataset
Beijing PM2.5 dataset (2010–2014), obtained from
the UCI Machine Learning Repository.

## Algorithms
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Project Status
Phase 1: Dataset collection and project setup.
